================================================================================
                        AUTHENTICATION FLOWS
================================================================================

SHOP AUTHENTICATION (OTP-Based)
  1. User enters phone number
  2. System sends OTP
  3. User enters OTP
  4. System validates and logs in
  5. Auth token stored in localStorage
  6. User can access profile and submit enquiries

ADMIN AUTHENTICATION (JWT-Based)
  1. Admin enters email and password
  2. System validates credentials
  3. System returns access and refresh tokens
  4. Tokens stored in localStorage
  5. Admin can access protected routes
  6. Tokens auto-refresh on 401 responses
  7. Permissions fetched and cached
